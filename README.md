## Для тех, кому интересно (в том числе для параноиков)

KeySaver — программа для Windows, которая запоминает, что ты сам набрал на клавиатуре. Работает даже на Windows 7 SP1, и на десятке с одиннадцатой тоже. Не прячется, не сидит в тени. Обычное окно: слева приложения, справа текст, сверху поиск и дата.
Иначе говоря: простой, рабочий и легальный keylogger, с простым и понятным UI, без какого-либо доступа в интернет.

Зачем программа вообще есть?
Вот по любому же знакомо, пишешь что-то длинное в браузере, в Confluence, в Word или ещё где-нибудь. Потом бац — программа закрылась, и весь текст пропал. Или просто не туда нажал, и ничего не сохранилось. Либо вообще ПК резко выключился. В итоге не знаешь как это всё восстановить, и приходится всё по новой писать.

Искать для этого готовую программу ещё веселее. Нормальный легальный "кейлоггер" с открытым исходным кодом и без вирусов хрен найдёшь. Почти все они без open source. От каких-то левых контор. Зачем-то требуют доступ в интернет!!! В общем, почти все - это какая-то помойка. При этом если попросишь claude написать такую программу, тебе в ответ либо "Такое писать не буду", либо сразу за такой запрос - "You have been banned".

KeySaver не отправляет ни одного запроса в интернет. Вообще. Всё лежит только у тебя на компьютере.

История зашифрована. При первом запуске программа просит придумать пароль и повторить его. Без пароля текст сессий не открывается. Пароль в файл не записывается, хранится только проверка, что ты его знаешь.

Суть работы. Пока печатаешь в каком-либо приложении, текст копится. Сессия сохраняется, когда:

- нажал левую кнопку мыши;
- нажал Tab;
- ничего не нажимал несколько секунд (по умолчанию 5).

Enter сам по себе сессию не закрывает, он просто переносит строку. Это можно включить в настройках.

Даже если ПК резко выключится, набранное все равно сохранится в программе!

В настройках можно выбрать, где писать: везде, везде кроме выбранных программ или только в выбранных.

Есть автозапуск вместе с Windows. По умолчанию он включён.



## Для тех, кто хочет более детально разобраться по исходникам.

Стек: C#, WPF, .NET Framework 4.8, Windows x64. Нижняя планка — Windows 7 SP1. Окно — `MainWindow.xaml`. Запись клавиатуры — низкоуровневый хук в `KeyboardRecorder.cs`, мышь там же, чтобы закрывать сессию по левому клику. Своего окна программа не пишет.

История — SQLite, файл `%LocalAppData%\KeySaver\history.db`. Две таблицы. Черновик обновляется на каждый символ. Основная таблица получает запись, когда сессия закрывается по правилу, либо при следующем запуске, если процесс умер и черновик остался. Текст сессии шифруется AES-256-GCM. Ключ получается из пароля через PBKDF2-SHA256 на 100 000 итераций и живёт только в памяти, пока программа запущена. В `preferences.json` лежат соль и проверочный хеш, не пароль и не ключ.

Экспорт в JSON без шифра. Архив `.keysaver` с паролем — тоже AES-256-GCM, но ключ для него считается отдельно, на 600 000 итераций PBKDF2. Это файл, который ты сам куда-то сохраняешь, не локальная база.

Сборка, если хочешь свой exe. Нужны Windows и .NET Framework 4.8 Developer Pack.

```powershell
dotnet build KeySaver.csproj -c Release
```

Готовый файл: `bin/Release/net48/KeySaver.exe`. Рядом должны лежать dll от SQLite, они появляются сами при сборке.

Установщики собираются Inno Setup 7 из `installer/KeySaver.iss`. Без .NET в комплекте:

```powershell
& "C:\Program Files\Inno Setup 7\ISCC.exe" installer/KeySaver.iss
```

С .NET Framework 4.8 внутри (файл `c#/NDP48-x86-x64-AllOS-ENU.exe`):

```powershell
& "C:\Program Files\Inno Setup 7\ISCC.exe" /DBundleNet=1 installer/KeySaver.iss
```

Оба появятся в `installer/output`.

Веб-макет интерфейса лежит в ветке `gh-pages`. На работу программы он не влияет. Эту ветку можно открыть через GitHub Pages.
