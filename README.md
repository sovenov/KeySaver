# KeySaver

Скачать готовые сборки можно здесь: [Releases](https://github.com/sovenov/KeySaver/releases).

Если ты не разбираешься в GitHub, тебе больше ничего на этой странице не надо. Жми ссылку выше, качай установщик, ставь. Исходники ниже — для тех, кому интересно, как это собрано.

## Для обычных людей

KeySaver — программа для Windows, которая запоминает, что ты сам набрал на клавиатуре. Работает даже на Windows 7 SP1, и на десятой с одиннадцатой тоже. Не прячется, не сидит в тени. Обычное окно: слева приложения, справа текст, сверху поиск и дата.

Зачем она вообще есть. Пишешь что-то длинное в браузере, в Confluence, в Word или ещё где-нибудь. Потом бац — программа закрылась, и весь текст пропал. Или просто не туда нажал, и ничего не сохранилось. Час работы, и как будто его не было.

Искать для этого готовую программу ещё веселее. Нормальный легальный «кейлоггер» с открытым исходным кодом и без вирусов хрен найдёшь. Либо помойка с рекламой, либо штука, которая ещё и пароли куда-то утаскивает. Эта — нет. KeySaver не отправляет ни одного запроса в интернет. Вообще. Всё лежит только у тебя на компьютере.

История зашифрована. При первом запуске программа просит придумать пароль и повторить его. Без пароля текст сессий не открывается. Пароль в файл не записывается, хранится только проверка, что ты его знаешь.

Как это работает в быту. Пока печатаешь в другом окне, текст копится. Сессия сохраняется, когда:

- нажал левую кнопку мыши;
- нажал Tab;
- ничего не нажимал несколько секунд (по умолчанию 5).

Enter сам по себе сессию не закрывает, он просто переносит строку. Это можно включить в настройках.

Набранное не ждёт, пока сессия закроется. Каждый символ сразу шифруется и пишется в черновик в той же базе. Когда срабатывает мышь, Tab или пауза, черновик переносится в обычную историю. Если KeySaver упадёт или компьютер выключится посередине, текст не пропадёт: при следующем запуске, после пароля, черновик сам станет обычной сессией.

Крестик окно не убивает, а убирает в трей. Слева внизу у часов остаётся значок. Левый клик по нему — открыть окно. Правый — меню: открыть, включить или выключить запись, завершить. Полностью программа закрывается только через «Завершить».

В настройках можно выбрать, где писать: везде, везде кроме выбранных программ или только в выбранных. Список программ берётся из тех, что уже есть слева. Если слева пусто, список тоже пустой. Чужую программу можно добавить кнопкой «Выбрать .exe».

Есть автозапуск вместе с Windows. По умолчанию он включён.

Два установщика:

- `KeySaver-Setup-1.0.0.exe` — только программа. Ставь, если .NET Framework 4.8 уже есть. На нормальной Windows 10 и 11 он обычно уже стоит.
- `KeySaver-Setup-1.0.0-net.exe` — то же самое плюс .NET Framework 4.8 внутри, если его нет. В установщике будет галочка.

Повторная установка стирает локальную историю и настройки. Это сделано специально, чтобы после установки база была пустая.

## Для тех, кто хочет разобраться

Код открытый. Параноикам можно скормить репозиторий любой языковой модели и спросить, ходит ли программа в сеть и что она пишет на диск. Можно не верить ни релизу, ни мне и собрать билд самому. Так даже спокойнее.

Стек: C#, WPF, .NET Framework 4.8, Windows x64. Нижняя планка — Windows 7 SP1. Окно — `MainWindow.xaml`. Запись клавиатуры — низкоуровневый хук в `KeyboardRecorder.cs`, мышь там же, чтобы закрывать сессию по левому клику. Своего окна программа не пишет.

История — SQLite, файл `%LocalAppData%\KeySaver\history.db`. Две таблицы. Черновик обновляется на каждый символ. Основная таблица получает запись, когда сессия закрывается по правилу, либо при следующем запуске, если процесс умер и черновик остался. Текст сессии шифруется AES-256-GCM. Ключ получается из пароля через PBKDF2-SHA256 на 100 000 итераций и живёт только в памяти, пока программа запущена. В `preferences.json` лежат соль и проверочный хеш, не пароль и не ключ.

Старые открытые JSON-истории не читаются. Экспорт в JSON по-прежнему без шифра. Архив `.keysaver` с паролем — тоже AES-256-GCM, но ключ для него считается отдельно, на 600 000 итераций PBKDF2. Это файл, который ты сам куда-то сохраняешь, не локальная база.

Сборка, если хочешь свой exe. Нужны Windows и .NET Framework 4.8 Developer Pack.

```powershell
dotnet build KeySaver.csproj -c Release
```

Готовый файл: `bin/Release/net48/KeySaver.exe`. Рядом должны лежать dll от SQLite, они появляются сами при сборке.

Установщики собираются Inno Setup 7 из `installer/KeySaver.iss`. Без .NET в комплекте:

```powershell
& "C:\Program Files\Inno Setup 7\ISCC.exe" installer/KeySaver.iss
```

С .NET Framework 4.8 внутри (файл `c#/NDP48-x86-x64-AllOS-ENU.exe`):

```powershell
& "C:\Program Files\Inno Setup 7\ISCC.exe" /DBundleNet=1 installer/KeySaver.iss
```

Оба появятся в `installer/output`.

Веб-макет интерфейса лежит в ветке `gh-pages`. На работу программы он не влияет. Эту ветку можно открыть через GitHub Pages.
